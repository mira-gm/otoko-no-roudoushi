# 男たちの労働史 — GitHub Pages用サイト

## 公開方法
このフォルダの中身をGitHubリポジトリのルートに配置し、GitHub Pagesを有効にしてください。

## ファイル構成
- `index.html`：トップページ・作品一覧
- `work.html`：各作品の絵本ページ
- `css/style.css`：デザイン
- `js/app.js`：作品一覧・CSV読み込み・場面ジャンプ
- `data/works.json`：作品一覧データ
- `works/作品ID/`：各作品のCSVと画像

## 作品の追加
1. `works/` の中に作品IDのフォルダを作成する。
2. CSVと `images/` フォルダを入れる。
3. `data/works.json` に作品情報を追加する。
4. 顔イラストができたら `portrait` に画像パスを指定する。

例：
`"portrait": "works/example/images/portrait.jpg"`

顔イラストが未登録の場合は「顔イラスト準備中」と表示されます。
作品の並び順は `order` の数字で指定します（縄文から現代への時代順を想定）。

## CSV形式
`index,id,year,image,title,description,character,dialogue`
画像パスは各作品フォルダ内の `images/` からの相対パスにします。

## 表示仕様
- トップページを開くと作品一覧を表示（年齢確認画面なし）
- 作品一覧は顔イラスト、時代・職業、サブタイトル
- 作品ページは1場面ごとにタイトル、セリフ・心の声、大きな画像の順に表示
- 画像下の説明文は表示しない
- 吹き出しなし
- 「次の場面へ ↓」で次の場面へスムーズにジャンプ
- ボタンを使わず、通常のスクロールでも読める
- 最終場面は読者へのメッセージとして区別
